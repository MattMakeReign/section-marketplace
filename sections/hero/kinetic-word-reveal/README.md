# Kinetic Word Reveal

Full-viewport centered display word where each letter is an interactive slot — on hover, the letter swaps to a media tile while neighbouring letters spring apart to accommodate it, then retract with a tilt-and-pop on release. No supporting copy or CTA; the word itself is the entire layout.
