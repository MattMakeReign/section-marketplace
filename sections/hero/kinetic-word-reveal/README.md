# Kinetic Word Reveal

Full-viewport centered display word where each letter is an interactive slot — on hover, the letter expands into a media tile while neighbours spring aside to make room; tile holds briefly then retracts with a tilt-and-pop. Layout is typographic-only at rest, image-grid on interaction.
