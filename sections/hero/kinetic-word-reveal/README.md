# Kinetic Word Reveal

Full-viewport centered display word where each letter is an interactive slot — on hover, the letter swaps to a media tile, neighbouring letters spring apart to make room, then retract with a tilt-and-pop. No supporting copy or CTA; the typographic interaction is the entire layout.

Motion density: high.
