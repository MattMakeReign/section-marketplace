# Sphere Rotate

Interactive 3D image sphere with items distributed along a Fibonacci spiral across a dark canvas. Drag, swipe, or scroll to rotate the sphere; inertia eases motion to a stop. Accepts a variable-length array of image slots with no fixed grid structure.
