# Pinned Project Spine

Pinned horizontal scrub of a project index. Inactive projects collapse to thin label spines (rotated 90°); the one closest to scroll progress activates and reveals its image at full width. Desktop-only effect; mobile falls back to a vertical stack. Adapted from mwg_038.
