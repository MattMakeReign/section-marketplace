# Drifting Cards

Pinned horizontal scroll with vertical-drift cards. Cards slide right to left while each drifts up/down on a yoyo half-sine, scale-pulses at center with a back.inOut ease, and rotates with a small random jitter. GSAP ScrollTrigger pin + containerAnimation. Headline locks to the project's heading-1 type role; surface/fg/radius all bind to design-system tokens, so the section adapts visually when pulled into another project.
