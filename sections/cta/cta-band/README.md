# CTA Band

Inverted full-width band with a single primary CTA. Closes a page.

## When to use

- Closing rhythm of a landing or case-study page where the brand has earned the ask
- When a single, unambiguous next step matters more than a menu of options

## When not to use

- As a section mid-page — it's a closer, not a connector
- When the page needs to offer two equal-weight choices (use a paired CTA layout)
